===============================================================================
STRATA – DOMAIN-DRIVEN DESIGN (DDD)
Simulador de Coerência Territorial e Uso da Terra
===============================================================================

VERSÃO: 0.1 (Fundacional)
STATUS: Em construção
LINGUAGEM: C++ (17/20)
FOCO: Simulação científica territorial baseada em coerência ecológica

===============================================================================
1. VISÃO GERAL DO PRODUTO
===============================================================================

O STRATA é um simulador científico territorial cujo objetivo é permitir a
exploração de hipóteses sobre o uso da terra a partir de relações biofísicas
e espaciais, respeitando solo, relevo, drenagem e padrões de organização
em manchas (patches).

O sistema NÃO prescreve usos da terra.
O sistema avalia a COERÊNCIA TERRITORIAL de hipóteses declaradas pelo usuário.

===============================================================================
2. PRINCÍPIO FUNDAMENTAL
===============================================================================

"O STRATA simula relações, não decisões."

O usuário declara:
- Recorte espacial
- Relações ecológicas relevantes
- Restrições espaciais (patches)

O STRATA responde com:
- Padrões emergentes
- Tensões internas
- Grau de coerência territorial

===============================================================================
3. CORE DOMAIN
===============================================================================

Nome do Domínio Central:
Territorial Coherence Simulation Core

Responsabilidade:
- Representar espaço territorial finito
- Integrar solo, relevo e hidrologia
- Avaliar padrões espaciais (patches)
- Simular potencial e coerência de uso da terra

O Core Domain NÃO conhece:
- Interface gráfica
- Renderização 3D
- Decisões humanas normativas
- Dados administrativos externos

===============================================================================
4. SUBDOMÍNIOS
===============================================================================

4.1 Subdomínio Biofísico
-----------------------
Responsável por:
- Terreno (elevação, slope)
- Solo (atributos físicos e funcionais)
- Hidrologia (drenagem, acúmulo, fluxo)

4.2 Subdomínio Espacial (Patch System)
-------------------------------------
Responsável por:
- Identificação de manchas
- Métricas de forma, tamanho e conectividade
- Regras espaciais de organização

4.3 Subdomínio de Uso da Terra (Potencial)
------------------------------------------
Responsável por:
- Representar tipos gerais de uso da terra
- Avaliar compatibilidade com condições biofísicas
- NÃO representa manejo ou decisão humana explícita

4.4 Subdomínio de Vegetação (Futuro)
-----------------------------------
Responsável por:
- Responder às condições geradas pelo uso da terra
- Simular estados biofísicos vegetais
- NÃO decide uso da terra

===============================================================================
5. LINGUAGEM UBÍQUA
===============================================================================

Termo                     Significado
--------------------------------------------------
Territory                 Espaço finito simulado
SoilProfile               Conjunto de atributos do solo
Terrain                   Estrutura geomorfológica
Hydrology                 Sistema de drenagem e fluxo
Patch                     Mancha espacial contínua
PatchMetric               Métrica de forma/estrutura
LandUsePotential           Potencial de uso da terra
TerritorialHypothesis     Declaração do usuário
Coherence                 Grau de consistência interna
SimulationRun             Execução controlada do modelo

Todos os termos devem aparecer:
- No código
- Nos documentos
- Na interface do usuário

===============================================================================
6. BOUNDED CONTEXTS
===============================================================================

1) BioPhysical Context
   - Solo
   - Relevo
   - Hidrologia

2) Spatial Pattern Context
   - Patches
   - Métricas espaciais
   - Regras de organização

3) Land Use Potential Context
   - Tipos gerais de uso
   - Compatibilidade biofísica
   - Avaliação de coerência

4) Simulation Context
   - Execução
   - Controle temporal
   - Parâmetros globais

5) UI / Visualization Context (externo)
   - Apenas visualiza resultados
   - Não altera regras científicas

===============================================================================
7. ENTIDADES
===============================================================================

- Territory
  Identidade: TerritoryID
  Representa o espaço territorial simulado

- Patch
  Identidade: PatchID
  Representa uma mancha espacial contínua

- LandUsePotential
  Identidade: LandUseID
  Representa um tipo potencial de uso da terra

- SimulationRun
  Identidade: RunID
  Representa uma execução do modelo

===============================================================================
8. VALUE OBJECTS
===============================================================================

- Elevation
- Slope
- SoilDepth
- DrainageIndex
- PatchSize
- PatchShapeIndex
- ConnectivityIndex
- CoherenceScore

São imutáveis e validados na criação.

===============================================================================
9. AGREGADOS
===============================================================================

Aggregate Root:
Territory

Contém:
- BioPhysical Layers
- Patch System
- LandUse Potentials

Todas as avaliações partem do Territory.

11. ANTI-CORRUPTION LAYER (ACL)
===============================================================================

- Adaptadores entre Core Domain e UI
- Adaptadores entre Core Domain e Renderização 3D
- Importadores de dados externos (opcional)

===============================================================================
12. CONSIDERAÇÕES FINAIS
===============================================================================

Este DDD define o STRATA como um simulador científico orientado à
exploração de hipóteses territoriais, priorizando coerência ecológica
e organização espacial, e preparando o terreno para a inclusão futura
de vegetação, manejo e dinâmicas socioecológicas.
