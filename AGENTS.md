# AGENTS

Este arquivo define expectativas para agentes automatizados no repositório.
Mantemos instrucoes curtas, claras e alinhadas com a fundacao cientifica.

## Objetivo
- Agentes servem para catalogar conhecimento do projeto e acelerar tarefas.
- Nao substituem decisoes cientificas nem alteram o Core Domain sem validacao.
- Agentes ampliam a legibilidade do sistema, nao sua autoridade cientifica.

## Regras basicas
- Priorize documentos em docs/ para fundamentar respostas.
- Nao invente dados cientificos; sempre cite a fonte no repo.
- Nao modifique modelos cientificos sem evidenciar a base documental.
- Mantenha separacao entre simulacao (core) e visualizacao (UI/3D).
- Agentes podem mapear conexoes entre documentos existentes sem criar novas interpretacoes cientificas.

## Saidas esperadas
- Resumos com referencias a arquivos.
- Listas de funcionalidades com aplicacoes e limitacoes.
- Propostas de doc com seccoes pequenas e claras; rascunhos nao sao canonicos e exigem validacao humana.
