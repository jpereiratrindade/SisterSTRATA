# SisterSTRATA v1.10.3

Data: 2026-02-25  
Tag: `v1.10.3`

## TL;DR

- F2 hardening evoluiu de telemetria para enforcement bloqueante no determinismo cross-runner.
- CI ganhou guard de higiene de repositório para bloquear artefatos de build rastreados.
- Testes sistêmicos cross-context agora incluem cenário deliberado de ingestão inválida + execução de infraestrutura.

## Highlights

1. Determinismo e CI
- Compare cross-runner agora é bloqueante em PR e `main`.
- Ambiente de determinismo padronizado em CI (`TZ=UTC`, `LANG/LC_ALL=C.UTF-8`).
- Toolchain de replay padronizada com `gcc-12`/`g++-12` e flags sem `fast-math`.

2. Governança executável
- Novo gate `GitArtifactHygieneGuard` para impedir `*.o`, `*.obj`, `*.lo` e diretórios de build rastreados no índice Git.
- ADR gates separados por famílias para facilitar triagem: contratos de aplicação, suítes científicas do core e guards estáticos.

3. Resiliência sistêmica
- Novo cenário adversarial em `CrossContextIsolationTest`:
  - tentativa de ingestão com `decisionDirective` inválido
  - execução de infraestrutura em seguida
  - verificação de preservação do estado cross-context.
