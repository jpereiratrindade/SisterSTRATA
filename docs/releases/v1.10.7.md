# SisterSTRATA v1.10.7

Data: 2026-02-25  
Tag: `v1.10.7`

## TL;DR

- Corrigida a política de gatilho do `STRATA-CI` para evitar ruído de execução em tags de release.
- Pipeline de determinismo endurecido para reduzir flakiness operacional em instalação de dependências.
- Metadados de release sincronizados para `1.10.7`.

## Highlights

1. Trigger canônico de CI para branches
- `push` agora executa em branches (`"**"`) e ignora tags `v*`.
- Evita runs duplicados/não-canônicos gerados no push de tag de release.

2. Robustez operacional do pipeline determinístico
- Etapas de instalação de dependências (`apt`) com retries/timeouts em:
  - `f1-hardening`
  - `f2-determinism-replay`
- `f2-determinism-compare` agora só executa quando `f2-determinism-replay` fecha com sucesso.
- `f2-determinism-stability-window` agora só executa quando `f2-determinism-compare` fecha com sucesso.

3. Evidência de validação
- Run canônico com as correções: `STRATA-CI #52` (success):
  - https://github.com/jpereiratrindade/SisterSTRATA/actions/runs/22403923914

4. Alinhamento de versão
- `CMakeLists.txt` -> `VERSION 1.10.7`
- `Doxyfile` -> `PROJECT_NUMBER 1.10.7`
- `docs/SCIENTIFIC_MODEL_VERSION.json` -> `engineVersion 1.10.7`
- `README.md`, `docs/README.md` e `CHANGELOG.md` atualizados.
